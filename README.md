# Path Integral Control in the Complex Plane

[![arXiv](https://img.shields.io/badge/arXiv-2610.34483-b31b1b.svg)](https://arxiv.org/abs/2610.34483)

Repository accompanying the paper:

> Aarón Villanueva, *Path integral control in the complex plane* (2026).  
> [Paper on arXiv](https://arxiv.org/abs/2610.34483)

## Overview

Path integral control formulates stochastic optimal control through weighted averages over state trajectories. When combined with stochastic quantum trajectories, it provides an alternative approach to quantum optimal control.

This work extends path integral control to the complex plane using circular complex Wiener processes. The change of measure is formulated on the driving noise space under an exact control–noise matching condition, allowing the framework to accommodate rank-deficient state diffusions.

Applied to stochastic Schrödinger equations, the formalism provides a compact treatment of paired non-Hermitian jump channels with unequal positive dissipation rates, together with cross-entropy-optimal feedback and open-loop control formulas.
